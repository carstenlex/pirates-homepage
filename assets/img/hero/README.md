# Fotos fuer die Startseiten-Slideshow

Die Fotos in diesem Ordner laufen als Hintergrund im Kopfbereich (Hero) der Startseite.

- Ordner: `assets/img/hero/`
- Formate: `.jpg`, `.jpeg`, `.png`, `.webp` (diese Anleitung wird nicht als Foto eingelesen)
- Anzahl: 3 bis 10 Fotos empfohlen. Bei nur einem Foto bleibt es statisch, ohne Fotos erscheint der Pirates-Hintergrund mit Logo.
- Groesse: Querformat, mindestens 1920 px Breite, vor der Verarbeitung moeglichst unter 500 KB je Datei. Hugo erzeugt automatisch die Varianten 800 px und 1920 px.
- Reihenfolge: alphabetisch nach Dateiname. Fuer eine feste Reihenfolge Dateien nummerieren, z. B. `01-halle.jpg`, `02-team.jpg`.
- Hinzufuegen/Entfernen: Datei in den Ordner legen bzw. loeschen, committen und pushen. Die Seite wird beim naechsten Build aktualisiert.
- Einwilligung: Bei Fotos mit erkennbaren Personen (besonders Minderjaehrigen) muss eine Einwilligung zur Veroeffentlichung vorliegen.
